# Seed Data Directory

All datasets in this directory are **100% simulated** for Lucknow prototype demonstration.

- `routes.json`: 4 bus routes (Route 23, 12, 7, 41) with polylines and headways
- `stops.json`: 16 stops (including Stop A and Stop B) with activity, lighting, ridership, skip rates
- `safeSpots.json`: safe waiting spots (pharmacy, petrol pump, 24h shop)
- `history.json`: 30 days of simulated waits, delays, skips, and ETA errors
- `reports.json`: ~45 simulated anonymous reports (Hindi and English)
- `incidents.json`: scripted demo timeline for stall, skip, and ghost bus events
